# Bijesh BJ, CMA — GitHub Portfolio

Static GitHub Pages portfolio for Finance, FP&A, Accounting, Financial Modeling & Valuation, SAP FICO, Data Analytics and AI-assisted Finance Automation.

## Publish
Upload the contents of this package to the root of `cmabijeshbj-web.github.io`, keeping `index.html` in the root. Then use GitHub **Settings → Pages → Deploy from a branch → main → /(root)**.

## Data policy
All demo workbooks and charts use synthetic/anonymized data. Do not publish confidential employer/client information, internal reports, credentials, API keys or proprietary screenshots.

The business scenario

A UAE mainland trading company files quarterly VAT 201 returns. Management wants the quarterly cash position, confidence that input VAT claims are valid, and proof that VAT-return turnover agrees to the accounts — the first thing the FTA tests in an audit. The workbook builds the return from the invoice register and flags every document that threatens a claim.

05

How it is built

  • VAT, recoverable input VAT, reverse-charge output/input and exception flags are formulas on every invoice row — nothing is pasted.
  • Select a quarter in Exec_Summary!C4 and the VAT 201 sheet re-cuts every box.
  • Reverse-charge purchases create equal output and input VAT (net zero), exactly as the FTA return treats them.
  • Controls: box 14 = executive net VAT, quarters = full year, monthly = quarterly, emirate split = box 1 total, every document categorised.
  • Rules reflect UAE VAT Law (5% standard rate, zero-rated exports, exempt supplies, blocked entertainment input VAT) — summarised for illustration.

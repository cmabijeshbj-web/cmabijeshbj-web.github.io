# Editing Guide — Bijesh BJ Portfolio

This site is plain HTML/CSS/JS — no build step, no installs. Open any file
in a text editor (or GitHub's own web editor — click the pencil icon on any
file in your repo), make a change, save, and it's live once pushed. This
guide covers the changes you're most likely to make yourself.

## The one thing to know: nav lives in ONE file now

The menu at the top of every page (Home / About / Experience / Projects /
Education & Certs / Resume / Contact) used to be copy-pasted into all 14
HTML files. It isn't anymore — it's now generated by `js/site.js` and
injected into every page automatically.

**To add, remove, rename, or reorder a menu link:** open `js/site.js` and
edit the `NAV_ITEMS` list near the top. That's it — every page updates.

```js
var NAV_ITEMS = [
  { href: "index.html",          label: "Home" },
  { href: "about.html",          label: "About" },
  // add a new line here for a new page, e.g.:
  { href: "publications.html",   label: "Publications" },
  ...
];
```

The footer (tagline, email, site link) and the site name/tagline shown in
the header also live in `js/site.js`, just below `NAV_ITEMS` — edit
`SITE_NAME`, `FOOTER_TAGLINE`, `FOOTER_EMAIL` there.

## Editing text on an existing page

Open the page's `.html` file and edit the text directly. Look for
`<!-- EDITABLE: ... -->` comments — they mark the blocks meant to be
changed. Everything else (the surrounding `<div>`s and `class="..."`
attributes) controls layout and styling — leave that structure alone,
just change the words between the tags.

Example — changing your professional summary on the Home page:
open `index.html`, find the paragraph starting "CMA (USA)-certified
Finance Professional...", and edit the sentence.

## Adding a photo anywhere

1. Put the image file in `assets/` (or a subfolder like
   `assets/certificates/` for certificate scans).
2. Reference it with a plain `<img>` tag:
   ```html
   <img src="assets/your-photo.jpg" alt="describe the image" style="width:100%; border-radius:4px;">
   ```
   For a photo inside a card, wrap it in `<div class="card">...</div>` to
   pick up the site's card styling automatically.

**Certificate images specifically:** the Education & Certifications page
(`certifications.html`) already has an `<img>` tag wired up for each
certificate, pointing at:
- `assets/certificates/cma-certificate.jpg`
- `assets/certificates/ima-data-analytics-certificate.jpg`
- `assets/certificates/uae-vat-corporate-tax-certificate.jpg`

Just drop your scanned certificate images into `assets/certificates/`
using those exact filenames (or edit the `src=` in `certifications.html`
to match whatever filenames you use) and they'll appear automatically. If
no image is present, each card shows a placeholder icon instead of
breaking — so there's no rush.

## Adding a new section to an existing page

Copy this pattern and paste it inside `<main>...</main>`, wherever you
want it to appear:

```html
<section class="section tight">
  <div class="wrap">
    <div class="section-head"><span class="num">03</span><h2>Your Section Title</h2></div>
    <p>Your content here.</p>
  </div>
</section>
```

Bump the number in `<span class="num">` to keep the numbering sequential
on that page (it's just a visual label, not a link).

## Adding a whole new page

1. Copy an existing simple page (e.g. `about.html`) and rename it, e.g.
   `publications.html`.
2. Replace the `<title>`, the `<meta name="description">`, and everything
   inside `<main>...</main>` with your new content.
3. Add one line to `NAV_ITEMS` in `js/site.js` (see above) so it shows up
   in the menu on every page.
4. If the new page lives inside `projects/`, use `../` in front of any
   link back to a root page (e.g. `../index.html`) — pages at the root
   don't need the `../`.

## Adding a new project

1. Copy an existing project page, e.g. `projects/fpa-variance-kpi.html`,
   and rename it.
2. Edit its content, stat numbers, and the download link at the bottom
   (point it at a file you've placed in `assets/downloads/`).
3. Add a matching project card to `projects.html` (the hub page) and to
   the "Featured Projects" section of `index.html` — copy one of the
   existing `<a class="project-card">...</a>` blocks and edit it.

## Colors, fonts, and overall look

All colors and spacing are controlled from `css/style.css` via CSS
variables at the very top of the file (`:root { --brass: ...; --teal: ...; }`
etc.). Change a value there and it updates everywhere that color is used,
site-wide. There's also a `[data-theme="light"]` block right below it —
that's the alternate warm/paper theme people can switch to.
